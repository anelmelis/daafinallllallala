# DAA Final Prep

Полноценное интерактивное приложение для подготовки к экзамену Design and Analysis of Algorithms.

## Что внутри

- 10 тем с конспектами на русском и терминами на английском
- 80 флеш-карточек с режимами «Знаю» и «Повторить»
- 71 MCQ-вопрос: 24 вопроса из предоставленных sample/additional questions и 47 дополнительных тренировочных вопросов
- Мини-квизы по каждой лекции (6–8 вопросов), проверка и объяснение сразу после выбора ответа
- Mock Final: 25 случайных вопросов, лимит 25 минут, оценка из 100 и разбор после завершения
- Java Practice Lab: 9 упражнений по 8 темам Implementation (Merge Sort, Kosaraju, DSU, Prim, Edit Distance, KMP Preprocessing + KMP Search, Rolling Hash, Kasai)
- Mistake Review, статистика, бэкап прогресса в JSON, переключатель темы, адаптивный интерфейс
- Всё сохраняется в localStorage текущего браузера, без аккаунтов и серверной базы

Внимание: Java Practice Lab проверяет фрагменты кода на соответствие эталонным решениям. Он не компилирует и не исполняет Java в браузере. Альтернативные семантически эквивалентные варианты могут не совпасть с эталоном.

## Сразу попробовать (без установки)

Открой `standalone/daa-final-prep.html` двойным щелчком в Chrome, Edge или другом современном браузере. Это полностью автономная HTML-версия с встроенным React, CSS и данными. Для онлайн-размещения предпочтительнее React + Vite вариант ниже.

## React + Vite: запуск локально

Требуется Node.js 18+ (рекомендуется LTS), npm.

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).

Для production build:

```bash
npm run build
npm run preview
```

Статические файлы окажутся в `dist/`.

## Как бесплатно опубликовать на Vercel

1. Распакуй архив с React-проектом.
2. Создай новый репозиторий GitHub и загрузи содержимое папки (на верхнем уровне должны лежать `package.json`, `index.html`, `src/` и `vite.config.js`).
3. На https://vercel.com выбери **Add New → Project** и импортируй репозиторий.
4. Framework Preset: **Vite**. Build Command: `npm run build`. Output Directory: `dist` (параметры уже указаны в `vercel.json`).
5. Выбери **Deploy**. Vercel выдаст ссылку на сайт. Для личного некоммерческого проекта можно использовать бесплатный Hobby plan с его ограничениями.

Официальная инструкция: https://vercel.com/docs/frameworks/frontend/vite

### Ещё более простой вариант: один HTML

Если нужен вообще без npm, можно взять файл `standalone/daa-final-prep.html`, переименовать в `index.html` и загрузить в статический проект Vercel. Отдельный архив `DAA-Final-Static-Vercel.zip` уже содержит его под нужным именем. Для регулярного развития сайта рекомендуем React + Vite.

## Где изменять контент

- `src/data.js`: 10 лекций (`lessons`), 71 вопрос (`questions`), 9 Java exercises (`labs`), полезные ссылки (`resourceLinks`).
- `src/app.jsx`: интерфейс React и логика сохранения/проверки.
- `src/styles.css`: дизайн и адаптивность.
- `src/main.jsx`: точка входа Vite.
- `scripts/build-standalone.py`: утилита, которой создавалась автономная версия в среде разработки. Для обычного Vite-деплоя не требуется. На другом компьютере для запуска standalone пересборка не нужна, готовый HTML уже в архиве.

### Пример добавления вопроса

В `questions` добавь элемент через функцию:

```js
makeQ(
  6,                         // номер лекции
  'Когда Kruskal пропускает edge?',
  ['Всегда', 'При создании цикла', 'При весе 1', 'Никогда'],
  1,                         // правильный индекс: B (отсчёт с нуля)
  'Если find(u)==find(v), вершины уже в одной компоненте.'
)
```

Вопросы автоматически попадут в соответствующие мини-квизы, Question Bank и Mock Final.

### Пример добавления карточки

Внутри нужной лекции добавь пару в массив `quick`:

```js
['Что делает Kasai?', 'Вычисляет LCP по готовому Suffix Array за O(n).']
```

Карточка создастся автоматически.

## Как сохраняется прогресс

Ключ localStorage: `daa-final-prep-progress-v1`.

Хранятся завершённые лекции, рейтинги карточек, история тестов, ошибки, завершённые Java-упражнения, настройки темы и незавершённый тест. Таймер Mock Final вычисляется по реальному timestamp, так что обновление страницы не сбрасывает время.

Прогресс не синхронизируется между браузерами/устройствами. В Progress доступны Export JSON и Import JSON для переноса. Очистка browser storage может удалить данные.

## Источники контента

Учебные конспекты переработаны на основе лекций и скриншотов, предоставленных пользователем ранее в этой беседе (10 тем), плюс предоставленные sample questions и расширенный список вопросов. Конспекты не являются дословными копиями слайдов. Там, где были неполные или разрозненные источники, добавлены ясно обозначенные тренировочные объяснения. Дополнительные вопросы написаны специально для практики и не заявляются как подлинные вопросы прошлых лет.
